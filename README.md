# Retail-Business-Intelligence-Customer-Segmentation-Analysis
## Dataset Information

The original Global Superstore dataset was cleaned and enriched in Excel using Power Query.

- Excel: cleaned_data.xlsx
- SQL: Imported as the `super_sales` table
- Python: Loaded from cleaned_data.csv
- Power BI: Uses cleaned_data.csv and customer_segments.csv

Although the naming differs across tools, all analyses were performed on the same cleaned dataset.

# Retail Business Intelligence & Customer Segmentation Analysis

## Project Overview

An end-to-end Data Analytics project analyzing 51,290 retail transactions from the Global Superstore dataset using Excel, SQL, Python, and Power BI.

The objective was to identify profitability drivers, customer behavior patterns, regional performance trends, and product opportunities to support data-driven business decisions.

---

## Tools Used

* Excel & Power Query
* MySQL
* Python (Pandas, NumPy, Scikit-Learn)
* Power BI

---

## Key Highlights

* Cleaned and transformed retail data using Excel and Power Query
* Performed business analysis using SQL (CTEs, Subqueries, Window Functions)
* Conducted Exploratory Data Analysis (EDA) using Python
* Built customer segmentation models (High Value, Regular, Low Value)
* Developed a 4-page interactive Power BI dashboard
* Generated actionable business recommendations

## Key Business Insights

* Discounts above 20% significantly reduced profitability
* Central Region generated the highest sales and profit
* Consumer Segment contributed over 50% of total sales
* High Value customers generated a significant share of revenue and profit
* November and December were the strongest-performing months
